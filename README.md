# KHAZANADRAW-Web-Application

KhazanaDraw is a web-based online lottery management system developed using **Laravel**.  
It provides a secure, transparent, and efficient platform for conducting digital lottery operations.

## ✨ Features
- **User System**: Registration, Login, Profile Management
- **Digital Wallet**: Deposit, Withdraw, Balance Management
- **Ticket System**: Purchase lottery tickets online
- **Automated Draws**: Fair and transparent draw process
- **Admin Panel**: Manage users, draws, and payouts
- **Secure Payments**: Integrated payment gateway

## 🛠️ Tech Stack
- **Framework**: Laravel 10
- **Database**: MySQL
- **Frontend**: Blade, Bootstrap, JavaScript
- **Other**: PHP 8.1+
